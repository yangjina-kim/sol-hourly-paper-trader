# 멀티자산 시간별 퀀트 단타 모의투자 시뮬레이터

GitHub Actions로 **매 1시간마다** 가상화폐(**솔라나 `KRW-SOL`**), 국내주식(**SK하이닉스 `000660.KS`**), 해외주식(**엔비디아 `NVDA`**) 3개 독립 계좌의 시세·1시간봉 캔들을 수집·누적하고, **1시간봉 단타 전용 정량 엔진(`quant-shortterm-v2`)**이 `매수 / 매도 / 관망` 결정을 내려 **누적 성과·거래 원장·종목별 전략지표 오버레이 차트·한국어 브리핑**을 GitHub Pages 웹 대시보드에 자동 갱신하는 프로젝트입니다.

- **라이브 웹 대시보드**: https://yangjina-kim.github.io/sol-hourly-paper-trader/
- **실행 주기**: 매시 17분 (`17 * * * *`, 정각 크론 폭주 회피용 오프피크 스케줄)
- **운영 방식**: 종목별 독립 모의 계좌 (외부 LLM API 키 불필요, 실거래 API 미연동)

## 전략 구조 및 리스크 안전장치 (`quant-shortterm-v2`)

| 항목 | 설정 값 | 설명 |
| --- | --- | --- |
| 단타 시그널 | 6팩터 복합 점수 (`-100 ~ +100`) | `EMA5/13` 초단기 추세(`±28`) · Fast `MACD(8,17,6)`(`±22`) · `12h VWAP`/돌파(`±18`) · `RSI(14)` 반등/과열(`±16`) · `4h` 중기 필터(`±8`) · 거래량/호가 수급(`±8`) |
| 진입 / 청산 규칙 | 매수 `≥ +24` (또는 과매도 반등) / 매도 `≤ -22` | 30~50% 분할 진입, 과열(`RSI ≥ 70` & 수익 `+1.2%`) 50% 분할 익절 |
| 단타 시간 손절 | `12시간` 횡보 정체 시 | `-0.8% ~ +0.8%` 박스권 정체 + 점수 `< +15`이면 전량 정리 |
| 슬리피지 | 3단계 동적 모델 (상한 `0.60%`) | 호가창 VWAP(암호화폐) / 기본 스프레드(주식) + ATR 변동성 가산(최대 `+15 bps`) + 주문 유형별 보정(손절 `+12 bps`, 익절 `1 bp`) |
| 최대 포지션 비중 | 계좌별 평가자산의 `70%` | 최소 30% 현금 완충 |
| 장중 손절 / 익절 | 손절 `-1.5% ~ -3.8%` / 익절 `+2.2% ~ +6.5%` | ATR 연동 + 수익 `+1.2%` 도달 시 본절+비용 이상으로 트레일링 상향 |
| 크론 중복·쿨다운 | 동일 1시간봉 중복 매수 차단 · 손절 1회차 쿨다운 | GitHub Actions 크론 지연으로 같은 봉 내 재실행 시 중복 진입 방지 |
| 일일 서킷브레이커 | 당일(KST) 낙폭 `-5.0%` 초과 시 | 당일 신규 매수 전면 차단 |
| 비교 벤치마크 | 종목별 단순 보유 (Buy & Hold) | 최초 실행 시점 전액 매수 가정 대비 초과수익(Alpha) 추적 |

## 모의투자 면책 안내

본 저장소는 전략 검증 및 자동화 학습 목적의 **가상 자금 모의투자 시뮬레이터**입니다. 실제 자산을 거래하지 않으며, 투자 조언을 제공하지 않습니다. 1시간 단위 암호화폐·주식 단타는 수수료·슬리피지 및 가격 변동성으로 인해 큰 손실이 발생할 수 있습니다.
