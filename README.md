## Gemini API 키 연결 방법 (선택 사항)

`GEMINI_API_KEY`를 등록하지 않아도 **정량 멀티팩터 폴백 전략**으로 매시간 정상 동작하며 한국어 브리핑이 자동 생성됩니다. Gemini AI 판단을 활성화하려면 아래 2단계만 설정하세요.

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급합니다.
2. GitHub 저장소의 **Settings → Secrets and variables → Actions → New repository secret**에서 아래 시크릿을 추가합니다.
   - Name: `GEMINI_API_KEY`
   - Secret: 발급받은 API 키
3. *(선택)* 모델을 변경하고 싶으면 **Variables** 탭에 `GEMINI_MODEL`을 추가할 수 있습니다. (기본값: `gemini-3.8-flash`, 오류 시 `gemini-3.5-flash-lite` 및 정량 폴백 자동 전환)
