    시뮬레이션 체결 환경

    • 시장 및 시세: 업비트 공개 API KRW-SOL 1시간봉·4시간봉·실시간 15호가 (장애 시 빗썸 자동 폴백)
    • 초기 가상 시드머니: 10,000,000원 (현물 전용, 레버리지·공매도 불가)
    • 거래 수수료: 체결 금액의 0.05% (업비트 원화 마켓 기준)
    • 슬리피지 반영 (3단계 모델): ① 업비트 실시간 15호가 잔량 소화 VWAP (하한 0.05% / 5 bps 또는 반스프레드) + ② 1h ATR(14) 0.8% 초과 시 변동성 지연 가산(최대 +15 bps) + ③ 주문 유형별 보정(장중 손절 +12 bps 급락 가산, 장중 익절은 지정가 성격으로 1 bp)
    • 벤치마크: 최초 실행 시점에 1,000만 원을 SOL에 일괄 매수해 보유한 Buy & Hold와 매시간 비교

    강제 리스크 가드레일

    • 최대 단일 종목 비중: 총 평가자산의 70% 상한 (항상 최소 30% 원화 완충)
    • 장중 손절/익절 감시: 매시간 실행 시 직전 1시간봉의 고가·저가를 검사해 손절(-1.5% ~ -5.0%) 또는 익절(+2.0% ~ +10.0%) 도달 시 자동 체결
    • 손절 직후 쿨다운: 장중 손절 체결 시 동일 회차 즉시 재진입(뇌동매매) 차단
    • 일일 서킷브레이커: 당일(KST 00시 기준) 누적 평가손실이 -5.0%를 초과하면 당일 신규 매수 전면 차단
    • 엔진 이중화: GEMINI_API_KEY 설정 시 Gemini AI가 판단하며, 미설정 또는 API 오류 시 정량 멀티팩터 전략으로 자동 폴백
